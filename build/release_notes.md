## [0.3.0] - 2026-11-24

### 改进

- **页面骨架**：工具栏、栏头、表头、行高、页脚读数与页内左栏都收进同一套尺寸，记账四页、股票六页、待办、事件、日记对齐到同一条基线和同一种节奏；侧边导航里展开的一级项变成分组标题，只有选中的子页带底色。
- **空态与文案**：页面空态改用应用自己的字阶与真实按钮，空表统一成「暂无 X + 一句下一步」；删除确认点名被删的对象，输入框占位符写成例子，空值一律用破折号。
- **天梯**：层级卡铺满窗口剩余高度，股票项在卡片内滚动，卡头等高，底部四项读数靠右成一组——窗口变高看到的是更多股票，不是更大的空白。
- **待办**：列表改成平铺表格，一行一件事；新建事项可以选已有主题或当场新建，主题能在弹窗里逐个管理或删除。
- **股票**：资金记录表按内容分配列宽（日期 120 / 事件弹性 / 金额 120 / 余额 120 / 备注 200），窄窗优先收固定列而不是裁描述；心得表行高与其它表一致，删除键回到安静的图标；持仓「当日涨跌」的百分比与浮动盈亏同档。
- **窄窗口**：960×620 下记录页的「描述」列、设置·数据备份的备份行、持仓的指标行都不再被裁；记录页的时间范围在 1020px 以下折成两行，主按钮独占第二行。
- **代理**：检测结果的状态点带说明，悬停能看到「上次检测：连通 / 失败」，读屏也能读到。

### 修复

- **代理检测崩溃**：点「检测」拿到结果后，状态点的提示框缺元素身份，下一次绘制会让应用直接崩溃退出。
- **负号位置**：负金额统一写作 `-¥1.00`，不再是 `¥-1.00`。
- **日记占位符**：看过去的日期时不再写「写下今天的日记」。
- **窗口按钮**：浅色标题栏上的最小化 / 最大化 / 关闭在悬停时没有反馈。
