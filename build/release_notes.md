## [0.1.4] - 2026-11-23

### 新功能

- **旧数据迁移日记**：`tr-import` 按旧账本把日记导入为日记本，保留日期、正文、字数、时间戳与心情，并把旧中文心情映射为 emoji。
- **股票图表动效**：折线图从左到右展开、饼图顺时针扫入，320ms 收束；统计曲线与指标的颜色语义同步整理。
- **全功能页统一框架**：记账、股票、待办、事件、日记使用同一套顶部工具栏、内容壳与侧栏宽度。

### 改进

- **股票详情**：持仓页与记录页统一为「交易台账 / 每日复盘 / 本轮复盘 / 成交记录」四段布局；台账摘要单行、止损止盈百分比同行、浮动盈亏单行；记录详情头不再溢出，心得关联轮次不再被截断。
- **股票统计**：明细表铺满内容区，窄窗横向滚动；预设曲线合计贴右，自定义曲线操作列居中；统计图表自适应剩余高度。
- **表格样式**：所有表格使用内缩表头带，移除表头与首行、表项之间的分隔线；分析表格列宽与对齐收紧。
- **待办**：表头移入每个主题的展开区；事项行压缩到 40px，移除表项分隔线；历史表事项列不再被压缩。
- **日期选择器**：修复日期格无法点击与两位数被裁切的问题。
- **图表与图标**：收束动效并统一无红绿语义指标的主色。

### 修复

- **股票**：记录详情头胜负轮次溢出；持仓页交易台账摘要字段换行。
- **桌面**：系统文件对话框改到绘制后打开，避免重复弹出并结束窗口。
- **更新**：下载过程中切换页面不再取消或从头开始。
