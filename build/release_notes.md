## [0.1.0] - 2026-11-23

### 新功能

- **记账**：记录、分析、标签、模板四页共用一个账本。记录页可以按时间范围筛选、排序、分页，右键编辑或删除；分析页有折线图、饼图和曲线表，既能用预设图表，也能自己建。
- **股票**：工作空间级多账户，分账户、持仓、记录、心得、统计、天梯六页。持仓和记录共用「交易台账 / 每日复盘 / 本轮复盘 / 成交记录」四段详情；统计给指标卡、曲线和明细表；天梯按连板高度分层。
- **待办**：列表和四象限两种看法，事项有六档紧急与重要度、开始与截止日期和进度记录；历史里能恢复、删除、订正。
- **事件**：一天一条，图片画廊、正文和跨账本关联交易放在一页；支持 JPEG、PNG、GIF、WebP、HEIC，缩略图在本地生成。
- **日记**：多个日记本，按年、月、日浏览，正文停止输入 600ms 后自动保存，可以记心情。
- **设置与备份**：通用设置、账本管理、股票设置、日记配置、数据备份和关于软件；备份可以立即备份、自动备份、恢复、删除单份，最近工作空间能切换或移除。
- **桌面外壳**：浅色与深色两套主题、自绘标题栏、单实例运行、最小化到托盘，更新检查走 GitHub Release。
