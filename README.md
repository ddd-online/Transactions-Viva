# Transactions

本地优先的个人记账桌面应用：一个工作空间内管理多个账本，覆盖记账、股票、待办、事件与日记。
所有业务数据只保存在用户自己选择的本地 SQLite 工作空间里。

## 当前状态

项目正在从 Electron + React 迁移到 **Viva + Go**，外壳、配置、记账四页、事件与日记已经可用：

- 根目录的 `main.go` 已是真实入口，能跑起窗口外壳（自绘标题栏、Viva Sidebar 导航、设置页、
  浅色 / 深色主题）。
- 记账-记录页有工具栏、时间范围、排序、表格、分页和收支统计。「记一笔」打开新增记录弹窗，
  行右键是编辑 / 同步到其他账本 / 删除，编辑复用同一个弹窗（模板 / 日期 / 类型 / 分类 /
  标签 / 标记 / 关联事件日期 / 描述 / 金额；日期带日历选择，标签可多选）。分页栏是 Viva 分页
  配一个每页 15 / 30 / 50 的 Select。
- 记账四页读写工作空间里的 `transactions.db`：账本、记录、分类标签、模板、分析图表都会持久化；
  空工作空间自动创建「默认账本」并播种旧工程的 19 个分类 / 57 个标签。没有工作空间时内容区
  显示「打开工作空间」门禁，设置里可切换目录。
- 日记页有年 → 月 → 日 的日期树（每天带心情与字数）、当天的正文与五个心情档；正文停 600ms
  自动保存，工具栏显示 已保存 / 未保存 / 保存失败，删除前确认。日记写在**日记本**里，和账本
  没有关系：工作空间可以有多个日记本，工具栏最左切换的就是它。
- 事件页按年浏览、一天一条：左侧是事件卡（身份色条、日期、摘要），中间是 20 档身份色、图片画廊
  （主图 + 160×90 缩略图、大图预览）与纯文本正文，右侧是关联交易。**事件属于工作空间，与账本无关**，
  所以这一页没有账本选择器；关联交易跨账本列出 `key_event_date` 等于该日期的记录，行里标出账本名。
  图片支持 JPEG / PNG / GIF / WebP / HEIC，缩略图与预览都在本机生成；HEIC 用纯 Go 解码器导入，
  展示图转成 JPEG、原图保留；实况照片只保存不播放。
- SQLite schema v1 → v5 带版本迁移（升级前写 `transactions.db.bak`）和损坏 / 版本检查。
  股票、待办表还没迁移，股票也不与账本关联。
- 记账-分析页有图表列表、折线图 / 饼图、时间范围、预设与自定义图表，图下方是曲线 / 分组的
  明细表，底部一条合计带。两张图都能悬停读数：折线提示某个月各条曲线的值，饼图提示某一组的
  金额与占比。
- 旧工程的账本 / 分类标签 / 记录 / 模板 / 图表 / 事件与事件图片可用 `cmd/tr-import` 导入（见下）。
- 设置 ·「日记配置」分「日记本」与「导入导出」两块：日记本可以新建 / 重命名 / 删除（最后一本
  留着）；导入按目录批量读 `YYYY-MM-DD.txt`（UTF-8 / UTF-16 / GBK 自动识别），导出按全部 / 年 /
  月写成同样的文件，两者都作用在日记页当前那本上。
- 股票与待办仍是 Sidebar 导航加占位空态；子功能作为 Sidebar 二级项（点击一级项展开，
  其他收起）。
- 配置会持久化，「通用设置」分「常规」（工作空间、外观、关闭行为）、「网络代理」（占位）与
  「功能开关」（五个功能，关掉即从导航移除）三组；「账本管理」可以新增 / 重命名 / 删除账本并写
  账本描述（最后一本不可删），「关于软件」显示版本 / 构建 / 平台 / 运行时，可复制版本信息、
  打开项目与问题反馈。`viva init` 的计数示例已移除。

## 开发

```sh
go run .                    # 打开原生窗口（文本输入可用）
viva dev .                  # 热重载开发；reload host 不转发原生文本事件
go test ./... -count=1      # 无窗口驱动测试 + 领域单测
go vet ./... && go tool viva vet  # 静态检查（CLI 版本由 go.mod 钉住）
viva build                  # 发布构建
```

> `viva dev .` 的热重载宿主只转发画面、指针与按键，不携带原生文本事件：所有 `ui.TextField`
> 在它下面都有光标却打不出字。需要测图表名称、记录描述这类表单输入时，用 `go run .` 或打包后的
> 原生窗口。

## 导入旧数据

```sh
go run ./cmd/tr-import -from <旧工作空间目录或 transactions.db> -to <新工作空间目录>
```

目标目录里不能已有 `transactions.db`，导入前请关闭旧应用。工具只读旧库，复制账本、分类、标签、
记录、记录标签、模板、图表、事件与事件图片文件；股票、日记、待办不导入。旧库的事件按账本存放，
本工程的事件属于工作空间，所以同一天在多个账本各有一条时只保留 `updated_at` 最新的一条作正文、
图片全部并入该日期，逐条写进报告。默认报告孤儿行（比如记录指向不存在的账本），加 `-strict` 则
遇到孤儿行就中止，不写入目标库。
