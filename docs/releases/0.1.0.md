# Transactions 0.1.0

首个公开发布版本，对应数据库格式 **schema v1**。

## 内容

- 记账：记录、分析、标签、模板四个页面，读取同一个本地工作空间。
- 股票：账户、持仓、记录、心得、统计、天梯六页。
- 待办：分组事项表、四象限、进度与历史。
- 事件与日记；日记按日记本隔离，支持目录导入导出。
- 设置：工作空间、外观、关闭行为、代理、功能开关、数据备份 / 恢复、更新检查。
- 旧 Electron 数据导入：账本、记录、分类标签、模板、图表、事件图片、股票与待办。

## 数据库

- 0.1.0 只有 **v1**，所有表和索引在 `internal/store/schema/0001_init.sql` 一次建好；没有增量迁移。
- 0.1.0 之前的开发版数据库版本为 2–7。打开时若已包含全部 v1 表，会先备份到
  `transactions.db.bak`，再把版本改写为 v1；缺表则拒绝打开。
- 旧 Electron 工作空间不直接打开，使用导入工具生成新的 v1 工作空间：

  ```sh
  go run ./cmd/tr-import -from <旧工作空间或 transactions.db> -to <新目录>
  ```

## 说明

- 本地优先：数据只保存在用户选择的工作空间目录；只有行情、天梯和更新检查会联网。
- Windows 构建使用未签名 zip；如需安装器，在装有 NSIS 的机器上运行
  `go tool viva package -target windows -format nsis`。
